# OFolium

O OFolium é uma aplicação desenvolvida para auxiliar microempreendedores na organização das informações de seus funcionários. O sistema busca substituir anotações em papel, mensagens dispersas e planilhas complexas por uma solução simples e centralizada.

## Situação atual

A interface e os principais fluxos de navegação já foram desenvolvidos e estão disponíveis para demonstração. Atualmente, a equipe trabalha na integração do frontend com o backend e com o banco de dados.

Acesse a versão navegável:  
https://o-folium.vercel.app/login

## Funcionalidades

- Cadastro e gerenciamento de funcionários;
- Registro de entradas e saídas;
- Controle de horas extras e faltas;
- Registro de vales, adicionais e descontos;
- Resumo mensal;
- Histórico de movimentações;
- Alertas de pendências.

## OFolium Pro

O plano Pro está sendo planejado para negócios que necessitam gerenciar uma equipe maior e utilizar recursos complementares, como:

- Gerenciamento de até 20 funcionários;
- Fechamento mensal preservado;
- Histórico completo;
- Revisão mensal por funcionário;
- Comparação entre meses;
- Relatório para o contador;
- Exportação em PDF, Excel e CSV;
- Alertas completos de pendências.
